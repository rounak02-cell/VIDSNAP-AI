# 🎬 VidSnap AI

> 🤖 AI-powered web application that transforms images 🖼️ and user ideas 💡 into short-form reels 🎥 through an automated content-generation workflow.

## ✨ Features

- 🖼️ Image-based input
- 💡 User idea/prompt input
- 🤖 AI-powered content generation
- 🔊 Text-to-speech audio generation
- 🎬 Automated reel creation
- 🌐 Flask-based web application
- ⚙️ FFmpeg-based video processing

## 🛠️ Tech Stack

- 🐍 Python
- 🌐 Flask
- 🤖 Generative AI
- 🔊 Text-to-Speech
- 🎬 FFmpeg
- 🖼️ Image Processing
- 🌐 HTML/CSS

## 🔄 Workflow

```text
🖼️ Image + 💡 User Idea
          ↓
     🤖 AI Processing
          ↓
   ✍️ Content Generation
          ↓
    🔊 Text-to-Speech
          ↓
    🎬 Video Processing
          ↓
      🎥 Final Reel
